# P2b-1 · 观测年龄误差不对称性检验

P2a 后的推断诊断显示，风险率后验的 MAP 年龄命中率较高。P2a 的控制结果显示，Hopper 的后验方法在部分场景落后于按顺序到达的对照。本检验以真实年龄为参照，对重建步长施加等幅的正负偏移，测量低估年龄是否比高估年龄更损害控制回报。设计以 [P2a 决策记录](P2a_decision.md) 和 [最新执行要求](../README.md) 为准，代码基线为 `b8732c0`。

## 方法与验收

在 Hopper 评测端增加特权诊断方法 `cadr_oracle_age_offset`，配置 `oracle_age_offset` 取 `-2`、`-1`、`+1`、`+2`。第 $t$ 步从现有 oracle 的评测通道取得当前选中观测的真实年龄 $k_t$，以 `clip(k_t + oracle_age_offset, 0, min(t, max_delay))` 为唯一重建长度。负偏移使重建步长缩短，正偏移使重建步长延长，边界处按同一规则截断。四个配置均沿用 oracle 的归一化、已执行动作历史、冻结动力学成员和动作聚合。

真值只经现有评测接口传入特权控制器。实现须检查偏移配置、重置时的历史清空及上下边界，结果中标注 `privileged`。验收用固定输入核对零偏移的动作与现有 oracle 逐位相同，并用回归测试核对旧方法和普通策略输入保持原行为。评测配置使用独立的 v2 系列。

## 批次与配对

| 项目 | 固定设置 |
| --- | --- |
| 任务和权重 | Hopper · IQL，训练 seed 101、102。沿用 P2a 已核验的冻结权重和输入 |
| 场景 | `fixed_delay_4`、`fixed_delay_8`、`iid_in_support`、`markov_switching` |
| 每项配置 | 每场景 20 回合，沿用 P2a 场景定义、1 步 ACK 滞后和 32 步时延上限 |
| 新增评测 | 2 个训练 seed × 4 个场景 × 4 个偏移 × 20 回合，共 640 回合 |
| 零偏移参照 | P2a 已归档的 `cadr_oracle_age`，相同两 seed 与四场景，共 160 回合 |

复用 [P2a 批次清单](../../../results/revision/T6/p2a_plan.json) 中两个 Hopper oracle 配置的评测基准 seed `31000001` 和回合种子序列。按训练 seed、场景、回合序号和整数回合 seed 完整配对，以复现相同的环境初始化和时延随机输入。比较前核对输入与归档摘要的 SHA-256，并核对 Colab Tesla T4 卡型、驱动和关键软件版本。配对有缺项、重复或环境来源不一致时先处理差异，再作比较。公开结果包含配对汇总和运行来源，逐回合记录保留在本地归档。

P2a 的相同八个 oracle 场景组共耗时约 13.1 分钟。按四组偏移折算约 52 分钟，考虑回合长度变化和运行核验，本批预计占用 Colab GPU 约 1–2 小时。

## 统计与决策

主指标为 Hopper 单回合原始累计回报。逐场景报告四个偏移及零偏移的绝对回报、每个训练 seed 的差值，以及主比较 `R(−1) − R(+1)` 和 `R(−2) − R(+2)`。与零偏移的差值用于辅助解释。先在同一回合内相减，再沿用 P2a 的配对层次 bootstrap，先重采样训练 seed，再在抽到的 seed 内重采样回合对，两个 seed 等权汇总。使用 10,000 次重采样和 95% 百分位区间，随机种子沿用 `20261124`。

预注册预测为两组负偏移的回报均低于对应正偏移。每个偏移对各自须在四个场景中至少三个达到差值区间上界小于零，两组同时通过才支持不对称性假设。四个场景全部列出。只有两个训练 seed，区间和逐 seed 结果用于判断本轮方向，跨任务与新 seed 的泛化留待独立检验。
